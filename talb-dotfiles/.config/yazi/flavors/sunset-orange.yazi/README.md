# sunset-orange.yazi

"Sunset Orange": orange on dark grey, with a gold -> orange -> red gradient for accents.
It matches the k9s skin `~/.config/k9s/skins/sunset-orange.yaml` and the rest of the
sunset-orange set in talb-dotfiles.

Directories are bold light orange, regular files are light orange, and executables are bold amber.
Archives are ember, images apricot, media coral and documents light gold. The hovered
entry is a dark-on-gold bar, and gold is used for accents throughout.
